# Simple Stock Flow — Herramienta CLI de Poblado & Verificación

Utilidad de línea de comandos en Python para interactuar con **Simple Stock Flow** exclusivamente a través de la **API HTTP pública**, sin conexión directa a la base de datos MySQL.

---

## 🚀 Uso

```bash
# 1. Instalar dependencias
pip install -r requirements.txt

# 2. Sembrar datos de prueba (productos en diversas categorías y ventas)
python -m ssf_tool seed --url http://localhost:8080
```
